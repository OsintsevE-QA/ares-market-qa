# Устранение неполадок и настройка окружения

Документация по решению нестандартных проблем, возникших при настройке тестового стенда.

## 1. Docker: TLS handshake timeout при скачивании образов
**Симптом:** 
При выполнении `docker compose up --build` или `docker pull` возникает ошибка:
`Error response from daemon: failed to resolve reference... net/http: TLS handshake timeout`

**Причина:** 
Локальный провайдер блокирует прямые HTTPS-соединения с Docker Hub (`auth.docker.io`), либо DNS-серверы провайдера не могут корректно разрешить адреса регистров.

**Решение:** 
Включение VPN-сервиса. 
VPN позволяет обойти блокировку, после чего Docker успешно завершает TLS-рукопожатие и скачивает базовые образы (например, `python:3.12-slim`).

*Примечание: После успешной сборки образов (пока они в локальном кэше Docker) VPN можно отключать, если он мешает работе UI приложения.*
