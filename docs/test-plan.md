# Тест-план: AresMarket

## Область тестирования

В области тестирования: AUTH, CAT, CART, ORD, REV, LOC, BUG, FB, ADM, NAV.
Вне области тестирования: реальная оплата, email/SMS уведомления, нагрузочное тестирование.

## Критерии начала

- AresMarket поднят локально через `docker compose up --build`.
- UI доступен на `http://localhost:8000`, Swagger на `/api/docs`.
- Тестовые (seed) данные загружены: демо-аккаунты `nova / nova123` (colonist) и `admin / admin123` (admin).

## Критерии завершения

- Все тест-кейсы прогнаны, статусы зафиксированы в Матрице трассируемости.
- Отчёт о тестировании написан.
- Критичные и мажорные баги заведены в Issues и отражены в `defects/bug-log.md`.

## Окружение

- ОС: Windows 11 Home x64.
- Браузер: Chrome (актуальная версия).
- Docker Desktop + WSL2.
- VPN включён при сборке образов (см. `docs/troubleshooting.md`).

## Ответственности

- **QA (я):** планирование тестирования, написание финальных артефактов, прогон тестов, заведение баг-репортов и принятие решений.
