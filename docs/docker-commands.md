# Управление Docker-контейнерами AresMarket

Шпаргалка по управлению локальным стендом на основе `docker-compose.yml`.
Все команды выполняются из корневой папки склонированного проекта `ares-market`.

## 1. Полная остановка

### Вариант А: Остановить контейнер (данные сохраняются)
```bash
docker compose stop
```
Контейнер останавливается, но не удаляется. Благодаря политике `restart: unless-stopped`, после перезагрузки Docker Desktop он не запустится автоматически (так как был остановлен вручную).

### Вариант Б: Остановить и удалить контейнер (данные сохраняются)
```bash
docker compose down
```
Контейнер и сеть удаляются. Именованный том `ares-data` (БД и загрузки) остаётся на месте.

---

## 2. Запуск

### Обычный запуск (после `stop`)
```bash
docker compose start
```

### Запуск с созданием контейнера (после `down`)
```bash
docker compose up -d
```
*Флаг `-d` запускает контейнеры в фоновом режиме (detached), освобождая терминал.*

### Запуск с пересборкой (если менялся код приложения)
```bash
docker compose up --build -d
```

### Запуск в интерактивном режиме (логи в терминале)
```bash
docker compose up
```
*Остановка: `Ctrl + C`.*

---

## 3. Запуск с обнулением данных (полный сброс)

Полностью удаляет **все пользовательские данные**: базу SQLite, загруженные файлы, созданных пользователей. Приложение вернется к состоянию "из коробки".

**Шаг 1: Остановить и удалить контейнеры + том**
```bash
docker compose down -v
```
*Флаг `-v` (volumes) принудительно удаляет именованный том `ares-data`.*

**Шаг 2: Запустить заново**
```bash
docker compose up --build -d
```

## Быстрая шпаргалка

| Задача | Команда |
| :--- | :--- |
| Остановить (данные на месте) | `docker compose stop` |
| Остановить и удалить контейнер | `docker compose down` |
| **Полный сброс данных** | `docker compose down -v` |
| Запустить после `stop` | `docker compose start` |
| Запустить после `down` | `docker compose up -d` |
| Запустить с пересборкой | `docker compose up --build -d` |
| Посмотреть логи (follow) | `docker compose logs -f` |
| Посмотреть статус | `docker compose ps` |
