# Тестовый сценарий: TS-AUTH-001 - Регистрация нового пользователя и первый вход

## Описание

Новый пользователь (колонист) проходит полный цикл: регистрация с валидными данными -> автоматический переход на страницу входа -> успешный вход в систему -> отображение профиля с ролью `colonist`.

## Предусловия

- AresMarket запущен локально
- UI доступен на `http://localhost:8000`
- В базе данных нет пользователя с указанными email и username

## Шаги сценария

1. Открыть страницу регистрации
2. Заполнить все обязательные поля валидными данными (email, username, password)
3. Опционально заполнить full_name и выбрать colony из списка
4. Отправить форму регистрации
5. Подтвердить, что регистрация успешна (UI показывает сообщение об успехе)
6. Перейти на страницу входа (автоматически или вручную)
7. Войти в систему с только что созданными учетными данными
8. Проверить, что UI отображает username и badge роли `colonist`
9. Открыть профиль пользователя через `/api/auth/me` с полученным токеном
10. Проверить, что в профиле корректно отображается роль `colonist`
11. Проверить в таблице `users` запись с email/username из шага 2: `role = colonist`, `colony` соответствует выбранному значению

## Ожидаемый результат

- Регистрация проходит успешно
- Пользователь создан в базе данных: запись в `users` содержит email, username, role = colonist, colony из шага 3
- Вход с новыми учетными данными работает
- UI отображает правильную роль пользователя
- API `/api/auth/me` возвращает корректные данные профиля

## Связанные требования

- FR-AUTH-01 (регистрация с полями)
- FR-AUTH-02 (уникальность email/username)
- FR-AUTH-03 (валидация длины пароля)
- FR-AUTH-04 (логин и получение JWT)
- FR-AUTH-08 (профиль пользователя с полем role)
- FR-AUTH-09 (отображение роли в UI)

## Связанные тестовые данные

- TD-AUTH-REG-UI-001 (валидная регистрация со всеми полями)
- TD-AUTH-REG-UI-002 (валидная регистрация без опциональных полей)
- TD-AUTH-LOGIN-UI-001 (валидный вход colonist)
- TD-AUTH-LOGIN-API-007 (проверка `/api/auth/me` с валидным токеном)
